# Виртуальная машина

Проект создан в учебных целях. Его основная задача — разобраться в устройстве простого процессора, принципах работы ассемблера и дисассемблера, а также в том, как машинный код исполняется процессором.

Мною были реализованы стековый процессор, ассемблер и дисассемблер на C. Программа предназначена для операционной системы WINDOWS.
Процессор умеет выполнять арифметические операции, работать с регистрами и памятью, выполнять переходы и вызовы функций, а также рисовать простые изображения.


## Структура проекта

-processor.cpp —  выполняет процессорные команды
-assembler.cpp — переводит ассемблерный код в машинный код.
-disassembler.cpp — переводит машинный код обратно в ассемблерные команды.
-enum_commands.h — содержит коды и названия команд, а также регистры.
-stack_test.cpp — реализация стека, используемого процессором.



## Возможности

-Стековые вычисления.
-Четыре регистра: AX, BX, CX, DX.
-Арифметические операции: сложение, вычитание, умножение, деление и извлечение квадратного корня.
-Ввод и вывод чисел.
-Условные и безусловные переходы.
-Вызов и возврат из функций.
-Оперативная память на 2601 ячейку.
-Рисование изображений на основе содержимого памяти.
-Сохранение машинного кода в бинарный файл.



## Команды процессора

PUSH - Помещает значение, регистр или значение из памяти на стек 

POP -  Снимает значение со стека и записывает его в регистр или память 

ADD -  Складывает два числа 

SUB - Вычитает одно число из другого 

MUL - Умножает два числа 

DIV - Делит одно число на другое 

SQRT - Вычисляет квадратный корень

IN - Считывает целое число 

OUT - Выводит число 

JMP - Безусловный переход по метке

JA, JAE, JB, JBE, JE, JNE  - Условные переходы по метке

CALL    Вызывает функцию, запоминается следующая команда

RET -   Возвращение из функции к последней запомнившейся команде  

DRAWC - Выводит изображение в консоль

DRAWW - Открывает графическое окно и рисует изображение

HLT -   Останавливает программу 

:(метка 0 - 8) - запоминается место в машинном коде для прыжка

# Виртуальная машина

- assembler.cpp                — переводит ассемблерный код в машинный код.
- disassembler.cpp             — переводит машинный код обратно в ассемблерные команды.

g++ processor.cpp -o processor.exe

## Особенности

- При ассемблировании используется технология двухпроходности.
- Процессор работает только с целочисленными значениями.
- Количество меток ограничено — от 0 до 8.
- Для поиска команд используются хеширование DJB2 и бинарный поиск.
- Команды хранятся в бинарном виде с использованием битовых полей.
- Для работы с изображениями используется библиотека Raylib.

## Стек

Для работы процессора используется собственная реализация динамического стека.

В стеке предусмотрены три режима проверки:

- DEBUG_MODE — проверка корректности стека.
- CANARY_MODE — проверка защитных значений до и после массива данных.
- HASH_MODE — проверка хеша стека и его данных.

При увеличении количества элементов вместимость стека увеличивается в 2 раза, а при уменьшении — сокращается в 4 раза.
